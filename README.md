# LPX Site Base: Um Template Moderno para Landing Pages


  
## 🔗 Demo Ao Vivo

Você pode ver o template em ação [**clicando aqui**](https://felipelopessz.github.io/Site-base-lopes/ ).



## 📖 Sobre o Projeto

Este é um template de site "base", criado para servir como um ponto de partida rápido e elegante para desenvolvedores e criadores. O objetivo foi construir um layout limpo, moderno e facilmente customizável, utilizando apenas HTML, CSS e JavaScript, sem a necessidade de frameworks complexos.

  


## ✨ Funcionalidades

- **Design Moderno:** Interface escura com uma paleta de cores profissional e layout limpo.
- **Estrutura Completa:** Inclui página inicial (Home) e uma página de produto/detalhes.
- **Componentes Reutilizáveis:** Navbars (desktop e mobile), rodapé, formulários e seções de features.
- **Fácil de Customizar:** Código organizado em `assets` (CSS, JS, Imagens, Vendor) para facilitar a customização.

  


## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3** (com Flexbox/Grid para layout)
- **JavaScript**
- **Bibliotecas de Terceiros (Vendor):** Bootstrap, jQuery, Fancybox, ScrollReveal, e outras.

  


## 🚀 Como Utilizar

1.  Faça o clone ou o download deste repositório (`git clone https://github.com/felipelopessz/Site-base-lopes.git` ).
2.  Abra a pasta do projeto e edite os arquivos `index.html` e `pagina02.html`.
3.  Altere os textos, imagens (na pasta `assets/images`) e estilos (em `assets/css/custom.css`) conforme sua necessidade.
